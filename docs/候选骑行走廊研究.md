# 候选骑行走廊研究

## 研究结论与证据等级
以下是依据区域地理关系提出的 **H 走廊假设**，供后续真实路网查询；尚未证明任一走廊全程可骑。当前没有获取真实沿道路轨迹，所以距离、累计爬升、最长连续坡、隧道清单全部为 **U**。没有把城市间直线距离、汽车导航里程或既有经验数字当成真实骑行距离。

本阶段至少提出两条值得核实的现实地理走廊，但“至少两条已验证现实可行路线”的验收尚未达到，原因是道路数据与现场通行证据缺失。不能据此制定出发路书。

## 共同约束及变体
汉阳在长江以北、汉江以南侧的城区格局意味着从北/东北入城时应特别检查汉江过江方式（地理背景 H，具体点位 U）；不把“到武汉”当成已到汉阳。每条桥的非机动车规定、入口、车道连续性和当日管制需核查，不默认轮渡运营、可载自行车或符合到达时段。不应为减少距离引入不允许自行车的快速路。

B 的襄阳以南可另比较经宜城—钟祥—京山—汉川到汉阳的走廊，以检查平原/丘陵、汉江跨越和补给权衡；目前仅为支线检索，不增加一条伪精确路线。河谷并不保证平缓：支沟绕行、跨河、上台地、隧道绕行都会增加爬升。

## 路线评价方法
先做硬性否决：明确禁行、关键连接断裂、无法安全穿过的隧道且无绕行、灾害封控、在可用时间内无法到达安全停留点。其余候选比较真实距离、爬升与长坡、未知路面占比、货流/无路肩暴露、隧道长度与照明、补给间隔、住宿备选、撤离能力、炎热和暴雨暴露。不要在硬风险未解时给总分排序。

未知路面必须单独统计：确认铺装里程 / 总里程，未知里程 / 总里程；缺失标签不计入良好铺装。节点城镇只是查找住宿补给的候选，不代表已确认酒店、水源、营业时间或车可入室。优先规划可缩短的一日段和至少一个不依赖同一桥隧的撤离方向。

距离验收：所有段起终点坐标统一、骑行权限筛选、几何无跳点、交界连接检查；API 距离与轨迹椭球距离差异需解释，保存输入、响应时间和服务模式。未经这些检查不填写“真实骑行距离”。
