## 数据最低接收标准
道路：源、许可、更新时间、模式、坐标系、geometry、方向、access/bicycle、oneway、surface、smoothness、隧道/桥梁、未知字段。路面/货流/照明可来源于官方说明或近期现场证据，不由 road class 推断。
高程：产品/版本、采样日期、像元大小、水平/垂直参考、NoData、覆盖、校验值；如无高程不得填零。
气象：站点经纬度/海拔、时间区间、时区、单位、缺测比例、观测/预报身份。不同海拔站点不能直接替代山口。
住宿/补给：实际地点、营业时间、最近确认日、联系/预约状态、可存车与取消条件，不保存不必要的私人信息。

## 授权与更新
当前没有抓取受限数据、调用私有接口或绕过代理；没有导出实验或正式 GPX。仅有内存合成测试样本。未配置 API Key，无凭据进入版本文件。后续真实 GPX 可能含个人位置，默认先在仓库外处理，审核后再加入。第三方源快照用于本地审计，公开仓库前核对许可证和必要署名。
网络重新开放后应重跑并归档旧证据；道路管制按最新公告和现场情况更新。不会因旧轨迹中出现一条路就永久标记为可通行。
