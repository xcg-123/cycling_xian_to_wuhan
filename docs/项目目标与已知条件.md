# 项目目标与已知条件

研究日期：2026-11-10（中国标准时间）；目标出行期：2027 年 7—8 月。阶段：技术验证和走廊筛选，非出发路书。

## 目标与验收边界
从西安交通大学骑公路车至武汉汉阳区，建立可追溯、可更新的道路与地形证据。优先顺序为合法通行、人员安全、路线连续与可撤离、路面适配、补给住宿、时间与骑行体验，最后才是距离优化。200—250 km 是初步日均目标，不是每天必须完成的任务；山区不设硬里程。最终方案允许休息日、缩短行程、绕行或公共交通撤退，但撤退不算完成纯骑行。

验收状态采用四类：**V 已实际验证**（注明对象和范围）；**D 资料支持、未独立实测**；**H 合理推测或研究假设**；**U 无法确认**。另用“用户条件”标明用户提供的信息，不包装为实测。

## 已知条件
- 用户条件：已有一定长途经验，拟继续系统训练约 8 个月；当前能力与未来能力均没有量化证据。
- 用户条件：公路车，夏季高温高湿与山区强降雨风险需重点分析。
- U：交大具体校区/校门、汉阳具体终点；目前不把兴庆校区当成已确认起点。校区差异会改变出城路径和里程。
- U：出发日、最长总天数、同行人数、后援、预算、可接受交通撤退方式。
- U：车型、胎宽/胎况、齿比、制动系统、轮组、负重、电源、照明、导航设备。
- U：连续多日负重骑行的移动速度、总耗时、爬升能力、热适应、补给耐受、伤病与恢复。

## 能力与时间预算
不预测“训练后必然可日骑 250 km”。分别建立目前已测、训练中更新、出发前验证三组能力档案。至少记录连续两至三日的距离、爬升、移动/总时间、气温、负重、补水进食、疼痛与次日恢复，逐步递增，避免为了验证计划强行完成高负荷。

示例仅作算术情景（H，不是用户表现）：移动均速 20/25 km/h 时，200 km 需要 10/8 小时移动；250 km 需要 12.5/10 小时。另加 2—4 小时休息、用餐、维修、城镇穿行，200 km 可能占 10—14 小时，250 km 可能占 12—16.5 小时。山区不能套用平路均速。

日程计算：可用移动时间 = 日落前到达期限 − 出发时刻 − 补给休息 − 天气停骑 − 故障缓冲。以实测负重能力推算能到达的安全住宿点，再确定里程。日照不等于可骑时段；午间避暑会显著压缩窗口。日照应按具体日期和经纬度计算，目前不固定日出日落时间。
